 🚀 QUICK START (First Time)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Install Docker Desktop
     → https://www.docker.com/products/docker-desktop

  2. Run setup script
     chmod +x quick-start-docker.sh
     ./quick-start-docker.sh

  3. Or use Make
     make dev-up

  4. Test it
     make test
     → Should see: {"status":"UP",...}

  make test-create-tenant  → Create test tenant
  make status              → Show container status
  make dev-up              → Build + start (recommended)
  make rebuild             → Clean rebuild
  make stats               → Show Docker resource usage

  ▸ Add to ~/.zshrc for quick aliases:
    alias deu='make dev-up'
    alias dlog='make logs-tail'
    alias dtest='make test'

  ▸ Watch logs while working:
    make logs-tail

  ▸ Check health quickly:
    make test

  ▸ Full clean rebuild:
    make clean && make dev-up

  ▸ Run multiple projects:
    Different ports: 8080, 8081, 8082, etc.
